# Buying guide: laptops for software development

Snapshot notes for Scout AI. Written from common public product guidance, not a live scrape.

## Memory

16GB is the floor for modern development with an IDE, browser, and containers. 32GB is more comfortable if you run Docker, Android emulators, or several language servers. 8GB machines bog down quickly.

## Display

A 14-inch 16:10 panel usually shows more editor lines than a 15.6-inch 16:9 1080p screen. OLED looks great for UI work but can be glossier outdoors.

## Battery and weight

For travel, prefer under about 3.2 lb and a larger battery pack. Ultrabooks win here. Gaming laptops with discrete GPUs trade battery life and noise for performance.

## Ports

Developers benefit from HDMI and more than two USB-C ports. Many thin laptops need a dongle for everyday peripherals.

## Price bands

- Under $700: student machines, usually weak for professional coding.
- Around $900–$1,100: first serious coding laptops if RAM is at least 16GB.
- $1,400+: repairability, better keyboards, discrete GPUs, or premium builds.
