# ASUS Zenbook 14 OLED

Source: https://www.asus.com/us/laptops/for-home/zenbook/
Category: product notes

## Config in catalog

Around $899 in this snapshot: Ryzen 7 8840HS, 16GB RAM, 512GB SSD, 14-inch OLED, about 2.82 lb, 75Wh-class battery.

## Strengths

Strong value under $1,000. OLED screen. Light enough to carry daily. Useful ports including HDMI on many configs. Good candidate for coding if 16GB is enough.

## Weaknesses

RAM is typically soldered. 512GB storage may need an external drive or cloud for large projects. OLED reflections outdoors.

## Fit

One of the better "first job" Windows coding laptops in this catalog when budget is under $1,000.
