# Microsoft Surface Laptop, 13.8-inch

Source: https://www.microsoft.com/en-us/d/surface-laptop-7th-edition/
Category: product notes

## Config in catalog

Around $999 in this snapshot: Snapdragon X Elite, 16GB RAM, 256GB storage, 13.8-inch touch display, about 2.96 lb.

## Strengths

Strong battery story on Snapdragon. Thin and travel-friendly. Nice Windows touchscreen experience.

## Weaknesses

Windows on ARM still has app compatibility gaps for some developer tools. Base storage is small. Port selection is limited compared with ThinkPads.

## Fit

Good travel Windows laptop if your toolchain runs well on ARM. Verify Docker and any native tooling before buying.
