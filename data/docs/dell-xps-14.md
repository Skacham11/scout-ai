# Dell XPS 14

Source: https://www.dell.com/en-us/shop/dell-laptops/xps-14-laptop/spd/xps-14-9440-laptop
Category: product notes

## Config in catalog

Around $1,649 in this snapshot: Core Ultra 7 155H, 16GB RAM, 512GB SSD, 14.5-inch high-res display, about 3.67 lb.

## Strengths

Sharp display for UI and design-adjacent work. Premium XPS chassis. Thunderbolt ports for docks and monitors.

## Weaknesses

RAM is soldered on these configs, so you buy the memory you need up front. Price rises quickly with upgrades. Heavier than Air / Framework class machines. 16GB can feel tight with heavy Docker use.

## Fit

Nice screen-first Windows laptop. For pure backend work, a ThinkPad or Framework with 32GB often gives more headroom per dollar.
