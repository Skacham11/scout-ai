# MacBook Air 13-inch (M4)

Source: https://www.apple.com/macbook-air/
Category: product notes

## Config in catalog

Base-ish config around $999: M4 chip, 16GB unified memory, 256GB SSD, 13.6-inch Liquid Retina display, about 2.7 lb.

## Strengths

Very light. Strong battery for office and coding work. Quiet. Good trackpad and display. Fine for web development, scripting, and many local tools on macOS.

## Weaknesses

Base storage fills up fast. 16GB unified memory is shared with the GPU. Not a Windows machine. No discrete NVIDIA GPU for CUDA-style workloads. Ports are limited to two Thunderbolt USB-C ports plus MagSafe and headphone jack.

## Fit

Good if you already want macOS and travel a lot. Less ideal if you need 32GB RAM on a budget or Windows-only software.
